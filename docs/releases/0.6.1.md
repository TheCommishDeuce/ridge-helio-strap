# New Strap Update

## What's new

- **A brand-new strap finishes its first sync.** A strap holds nothing from before the day
  it was first worn, and it answers those empty weeks a few minutes at a time. Each sync
  fetches at most 400 rounds, so the first sync stopped at heart rate (or later at the
  stress backfill) and the next one started again from the same place. Sleep, workouts and
  the summaries were never fetched. Now a sync that runs out of rounds remembers where it
  stopped and the next one continues from there. The steps after it still run, so sleep and
  workouts arrive from the first sync. A new strap catches up in a few dozen syncs, or a few
  if you restored the day from the Zepp cloud. Thanks to hexwreaker for the report and the
  fix (#1, #2).

No server update needed.
