## What's new

- **The phone works out every number itself.** Recovery, strain, sleep, Charge, VO₂max,
  the illness signal and every chart are computed on the phone from what the strap
  delivered, with the same formulas the server used (checked value for value against the
  server's own results). The app no longer needs the network to show anything.
- **The server is optional, and it is your backup.** Once a night, while the phone charges
  on Wi-Fi, everything the strap delivered, your profile and your journal go to the server;
  Settings → Back up now does it at once, and Settings warns you once the last backup is
  three days old. You can now set Ridge up without a server at all.
- **Restore onto a new phone.** Set up a new phone against a server that holds data and
  Ridge offers to restore it, then works every day out again on the phone.
- **Live steps on Today.** While Today shows today, the step count follows you as you walk.
- **Your profile and journal live on the phone.** Edit them under Settings → You → Profile
  and in the Journal; they reach the server with the next backup.
- A sync stopped from outside no longer leaves "Connecting…" on screen, and Back up now no
  longer leaves the upload bar behind.

**Update the app first, then your server, the same day.** A 0.3.0 app reads its numbers
from the server, and the 0.4.0 server no longer computes them, so update the phone before
the server. Until the server is updated too, the 0.4.0 app cannot copy your profile and
history from it and shows no numbers yet; once it is, the app copies them on its own (your
whole history, the old app's and any Zepp backfill included) and works every day out. No
database change this time. To update the server (deploy/README.md, "Updating"):

```sh
cd ridge-helio-strap && git pull && cd deploy && docker compose up -d --build
```

Without a server, just update the app.
