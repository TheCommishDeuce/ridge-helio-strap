# Sport Names Update

## What's new

- **Workouts say what they were.** A workout now shows its sport, such as Outdoor cycling,
  Climbing or Strength training, with a matching icon on Fitness, on the workout's page and
  on Today's timeline. A sport Ridge doesn't know yet shows as "Workout (code N)". Please
  report the code and what you were doing, and it will get a name.
- **Earlier workouts show as "Workout".** Ridge used to store the strap's timezone where the
  sport should have been, so it never knew the sport of any workout recorded before this
  update. Those workouts now say plain "Workout" rather than guess, and new ones get their
  sport. Biology's strength-training credit now finds strength and core workouts too.
- **Back goes back.** Back from Sleep, Fitness or any other tab now returns to Today
  instead of closing the app (#3).
- **The Strap page shows the strap's settings again.** It said "The strap reported none of
  the settings we know" while Diagnostics read them fine. It now asks the strap the same way
  Diagnostics does (#4).

**Server update recommended** if you back up to a server: the phone corrects the server's copy
of earlier workouts in its next backup either way, and the update also corrects any the phone
no longer holds. Server and phone can be updated in either order.
